# AGRONEXO

Plataforma web de apoio à agronomia. Interface, cálculos e integração ao catálogo AGROFIT/MAPA (dados abertos). O assistente Sebastião utiliza a API da OpenAI após configuração de chave no servidor.

> Ferramenta de apoio, não substitui receituário agronômico, responsável técnico ou rótulo/bula oficialmente vigente.
